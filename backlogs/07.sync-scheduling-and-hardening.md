# Phase 07 — Sync Scheduling & Hardening

## Goal
Make the admin hub run itself: periodically ingest + extract + generate
notifications in the background, with the security, secrets, and operational
polish needed for production on Render.

## Scope
- Background scheduler that chains ingestion (Phase 03) → extraction (Phase 04)
  → notification generation (Phase 06).
- Secrets wiring, encryption review, audit logging, error surfacing, docs.

## Background scheduler
- A tokio interval task spawned at startup in `main.rs` (guarded so it only runs
  when configured, e.g. `ADMIN_SYNC_ENABLED=true`).
- Runs on an interval (`ADMIN_SYNC_INTERVAL_SECS`, default e.g. 30 min):
  1. For each linked account: incremental Gmail + Drive sync.
  2. Run bounded LLM extraction on new sources.
  3. Regenerate notifications.
- Overlap protection: an advisory lock / `sync_runs` row so two runs can't
  overlap; exponential backoff on provider/API errors.
- A `sync_runs` audit table (started_at, finished_at, status, counts, error).

## Secrets & deploy
- Add all new env vars to `render.yaml` (`sync: false`, set in dashboard):
  `GOOGLE_CLIENT_ID/SECRET`, `GOOGLE_REDIRECT_URI`, `TOKEN_ENCRYPTION_KEY`,
  `SESSION_SECRET`, `OPENAI_API_KEY`, `OPENAI_MODEL`, `ADMIN_ALLOWLIST`,
  `ADMIN_SYNC_ENABLED`, `ADMIN_SYNC_INTERVAL_SECS`.
- Provide a local `.env.example`; never commit real secrets.
- Set the production `GOOGLE_REDIRECT_URI` to `https://baicebo.com/admin/auth/
  google/callback` and register it in the Google Cloud console.

## Hardening
- Review OAuth scopes are read-only and minimal.
- Confirm tokens + any sensitive fields are encrypted at rest; keys from env.
- Ensure `/admin/*` is uniformly behind `AdminSession` (add an integration test).
- Surface sync/extraction errors in the dashboard (last run status + message).
- Structured logging (no tokens / PII / secrets in logs).
- Rate-limit `/admin/sync` and `/admin/extract` manual triggers.

## Acceptance criteria
- With scheduling enabled, new emails/docs appear as todos/timeline/notifications
  without manual action.
- No overlapping runs; failures back off and are visible in the UI.
- All secrets sourced from env; none committed; scopes read-only.
- End-to-end pass: link accounts → auto-sync → dashboard reflects reality.
